# 3D Car Showroom (Modern OpenGL)

A 3D interactive car showroom environment built entirely with Modern OpenGL. The project features multiple indoor exhibition spaces and an outdoor street environment.

## 🚀 Tech Stack
* **Graphics API:** Modern OpenGL
* **Language:** C++

## ✨ Features
* 4 distinct indoor exhibition halls.
* Outdoor environment including streets and surroundings.
* 3D rendering and camera navigation.

## 🛠️ How to Run
1. Clone the repository.
2. Ensure you have the necessary OpenGL libraries installed (e.g., GLFW, GLEW).
3. Build the project using your preferred C++ compiler or IDE.
4. Run the executable.
